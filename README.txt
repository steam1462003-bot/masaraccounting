MASAR WEBSITE — PORTABLE PACKAGE

طريقة التشغيل
1. فك ضغط الأرشيف بالكامل إلى مجلد على الجهاز. لا تفتح صفحة HTML من داخل RAR أو ZIP مباشرة.
2. اترك مجلد masar-videos بجانب index.html، ولا تغيّر أسماء الملفات أو المجلدات.
3. افتح index.html في متصفح حديث مثل Chrome أو Edge أو Safari أو Firefox.
4. عند رفع الموقع إلى الاستضافة، ارفع index.html ومجلد masar-videos كاملًا مع الحفاظ على نفس ترتيب المجلدات.

إذا لم يعمل فيديو
- تأكد أن الأرشيف فُك بالكامل وأن مجلد masar-videos موجود بجوار الصفحة.
- استخدم متصفحًا محدّثًا يدعم فيديو MP4 بترميز H.264.

RUNNING THE WEBSITE
1. Extract the entire archive to a folder. Do not open the HTML page from inside the RAR or ZIP viewer.
2. Keep the masar-videos folder beside index.html. Do not rename the files or folders.
3. Open index.html in an up-to-date browser such as Chrome, Edge, Safari, or Firefox.
4. For hosting, upload index.html and the complete masar-videos folder at the same relative paths.
